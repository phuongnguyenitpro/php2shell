# Security Policy

Dự án phục vụ phòng vệ. Không đăng exploit, secret, log có thông tin nhạy cảm hoặc thông tin định danh vào issue công khai.

Nếu phát hiện lỗi trong script hoặc hướng dẫn, ưu tiên GitHub private vulnerability reporting nếu được bật. Nếu chưa có, tạo issue chỉ mô tả tổng quát để maintainer cung cấp kênh liên hệ riêng.

Lỗ hổng PHP Core cần báo cáo tới [PHP Security](https://www.php.net/security.php). Dự án không đại diện PHP Group. Các script chỉ kiểm tra cục bộ, không khai thác hoặc vá lỗi tự động.
